SHOPEASY - MINI E-COMMERCE PROJECT

How to run:
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser, or use Live Server.
4. Add products to cart, change quantities, remove products and try Checkout.

Files:
- index.html: HTML structure
- style.css: attractive responsive design
- script.js: product objects, dynamic rendering, cart and checkout logic

Internet is needed for product photos and Google Fonts.
This is a front-end demo. Checkout does not process real payments.
